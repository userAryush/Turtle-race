# Turtle-race




<p>This code is written in python. <br>A fun turtle race simulation built using Python's `turtle` module. The game asks you to input number of racers, then turtles will pop up one by one and starts to race, at the end it will specify the winner in the terminal </p>

## Features

- Choose number of racers (2 to 10)
- Randomized turtle movement
- Declares winner based on finish line
- Colorful visual race using turtle graphics

## How to Run

```bash
python turtle_race.py
